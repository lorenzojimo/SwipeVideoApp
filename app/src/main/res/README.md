# SwipeVideo – Swipe Video App for Android

A vertical swipe video app written in Java with XML layouts.
Swipe up or down to move between 5 online videos. Each video shows a
title, description and unique video ID. Tap to pause and resume.

## Features
- Vertical swipe navigation (ViewPager2)
- Videos streamed from online URLs (Media3 / ExoPlayer)
- Custom app icon and in-app logo
- Javadoc comments on all classes and methods

## Build and run
Open the folder in Android Studio, let Gradle sync, and run on an emulator
or device (API 26+).
